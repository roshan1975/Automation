## 1. Project Title

Search Engine Automation — Python Selenium Project

## 2. What Is This Project?

This is a simple web automation program made with Python and Selenium.

It automatically opens different search engines and searches for different queries.

The program searches on:

- Google
- DuckDuckGo
- Bing
- Yahoo
- Yandex

## 3. Why Did I Make This?

I made this project to practice Python and learn the basics of **Selenium Web Automation**.

It helped me learn how to open websites, find search boxes, enter text, and perform searches automatically.

It is a beginner-level learning project.

## 5. What Did I Learn?

This project uses Selenium to automate searches on multiple search engines.

The program:
- Opens different search engines
- Finds the search box
- Enters search queries
- Presses the Enter key
- Waits for the search results
- Repeats the process automatically
